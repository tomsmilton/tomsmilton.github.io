I want posting quick notes to be as easy as possible. I'm currently sat at a cafe on Mount Etna having just completed the 18km, 1800m climb to get here.

So here's my workflow idea.

- I'll have a google doc called Quick Notes. In it are two main tabs: Drafts and Complete.
- Under these I'll make sub tabs, as I write this note is a sub tab under drafts.
- I'll have Quick Notes posted to my website by setting up a schedule Claude session. This session will check this Google Doc, see if there are any new notes that have been moved to sub tabs of the “Complete” tab, and post them to the Quick Notes page of my website

Now I'm going to ask Claude to implement this from my phone and see if it's all done by the time I'm home.
